# Prime Reversible Squares

Starter files for the CS3520 prime reversible squares example.

## Files

- `model.c`: C starter file.
- `model.cpp`: C++ starter file.

## Build

Compile the C version:

```bash
gcc -Wall -Wextra -std=c11 model.c -o model-c
./model-c
```

Compile the C++ version:

```bash
g++ -Wall -Wextra -std=c++17 model.cpp -o model-cpp
./model-cpp
```

## Notes

Add the class implementation here as the example develops. Keep any alternate versions or experiments in clearly named files.
