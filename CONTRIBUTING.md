# Contributing

This repository is used by students across offerings of CS3520, so changes should be easy to understand, easy to run, and organized by course year.

## Adding a New Example

1. Create a folder under the correct year:

   ```text
   examples/<year>/<example-name>/
   ```

2. Add source files and a `README.md`.
3. Include compile or run commands.
4. Keep the example focused on one class topic.
5. Avoid committing generated files, binaries, editor folders, or local configuration.

## Example README Checklist

Each example README should answer:

- What topic does this demonstrate?
- What files should students inspect first?
- How do students compile or run it?
- What should students try changing?

## Pull Requests

When submitting changes:

- describe the class topic or purpose of the change
- mention any required compiler, runtime, library, or tool
- include enough instructions for a student to reproduce the result
